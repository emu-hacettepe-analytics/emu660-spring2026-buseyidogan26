(a)

I choosed to watch and analyze ‘Conversations on Data Science and Industrial Engineering - Baykal Hafızoğlu & Erdi Daşdemir’

Brief Summary: In the video, the speakers discuss how Operations Research (OR) has increasingly focused on artificial intelligence (AI) and machine learning in recent years. They explain the Value Complexity framework, which classifies analytics into four types: descriptive, diagnostic, predictive, and prescriptive.

Descriptive analysis aims to strengthen current performance. Techniques such as data mining and data visualization are commonly used.Diagnostic analysis focuses on interpreting hypotheses to understand and diagnose the current situation. Methods like hypothesis testing and clustering are important in this stage. Predictive analytics anticipates future behavior, making machine learning particularly relevant in this area. Prescriptive analysis can be thought of as providing recommendations or “prescriptions.” Optimization and mathematical modeling are heavily applied to determine the best course of action.

The video also emphasizes the importance of understanding the connections between different courses taken during undergraduate studies to gain a high-level perspective. In practice, descriptive, predictive, and prescriptive analyses are often used together. For example, in banking, these methods can be combined to assess the creditworthiness of a customer. Analytics solutions can be implemented as out-of-the-box tools or custom-made solutions, depending on the context.

Finally, the speakers stress that clearly defining the problem is essential. Defining the problem properly allows subsequent steps, such as KPI identification, model development, and output delivery, to proceed effectively. In addition to modeling, attention must be paid to the user interface (UI) and usability, ensuring that solutions can be effectively utilized by end users.

Custom Summary Function

The function compute_stats calculates several descriptive statistics for a numeric vector.

It returns the mean, median, variance, interquartile range (IQR), minimum, and maximum values as a named list.

compute_stats <- function(x) {
  list(
    mean = mean(x, na.rm = TRUE),
    median = median(x, na.rm = TRUE),
    variance = var(x, na.rm = TRUE),
    IQR = IQR(x, na.rm = TRUE),
    min = min(x, na.rm = TRUE),
    max = max(x, na.rm = TRUE)
  )
}

In this section, all missing values in the dataset are replaced according to the specified rules.

For numeric columns, missing values are replaced with my_birth_year + k. For character or factor columns, missing values are replaced with a string created using paste0(my_first, "_", k).

The modified dataset is stored as a new object called new_data, leaving the original dataset unchanged.

new_data <- polls_us_election_2016

for(col in names(new_data)) {
  
  if(is.numeric(new_data[[col]])) {
    
    new_data[[col]][is.na(new_data[[col]])] <- my_birth_year + k
    
  } else if(is.factor(new_data[[col]])) {
    
    new_data[[col]] <- as.character(new_data[[col]])
    new_data[[col]][is.na(new_data[[col]])] <- paste0(my_first, "_", k)
    
  } else if(is.character(new_data[[col]])) {
